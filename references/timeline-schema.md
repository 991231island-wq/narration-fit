# timeline.json

用户或上游工具提供。v1 不从视频里抽这段结构。

```json
{
  "title": "馒头为什么会胀起来",
  "segments": [
    {
      "segment_id": "s1",
      "start_s": 0,
      "end_s": 6,
      "label": "开篇案板",
      "visual": "案板上的面粉和一块还没发起来的面团"
    }
  ]
}
```

| 字段 | 必填 | 规则 |
|---|---|---|
| `title` | 否 | 只用于报告标题 |
| `segments` | 是 | 非空数组 |
| `segment_id` | 是 | 非空字符串，全文件唯一，改稿前后保持不变 |
| `start_s` | 是 | 秒，有限数字 |
| `end_s` | 是 | 必须大于 `start_s` |
| `visual` | 是 | 画面说明，非空。对齐文案时靠它，不靠猜镜头 |
| `label` | 否 | 短标签，例如「开场」 |

时间轴规则（脚本强制）：

- 段与段不能重叠。前一段的 `end_s` 等于后一段的 `start_s` 可以，这叫首尾相接。
- 中间留白可以，表示这段画面没有口播。留白不用凑字。
- 秒数按用户标注的十进制解释。预算用 `Decimal`，避免 `10 × 4.7` 被二进制浮点截成 46。

不合法的时间轴直接失败，错误里写明是重叠、`end_s` 不大、还是 `segment_id` 重复。不要在坏时间轴上继续改稿。

v1 不接受「帮我看这个 mp4 再写出 timeline」作为本 Skill 的步骤。用户要先有标注。
